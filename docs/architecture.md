# 系统架构说明

## 1. 技术架构

```
┌─────────────────────────────────────────────────────────┐
│                     Nginx (反向代理)                      │
│              localhost:80 → 前端静态 + API转发             │
└─────────────────────────────────────────────────────────┘
                              │
          ┌───────────────────┴───────────────────┐
          │                                        │
    ┌─────▼─────┐                          ┌──────▼──────┐
    │   前端     │                          │   后端 API   │
    │  Vue3     │◄───── REST API ──────────►│  FastAPI    │
    │  Element+ │      /api/v1/*            │  port:8000  │
    └───────────┘                           └──────┬──────┘
                                                  │
                                           ┌──────▼──────┐
                                           │   MySQL 8   │
                                           │  port:3306  │
                                           └─────────────┘
```

## 2. 前端架构

- **框架**: Vue 3 + Composition API + TypeScript
- **构建**: Vite 5
- **UI 库**: Element Plus
- **状态管理**: Pinia
- **HTTP**: Axios + token 拦截器
- **路由**: Vue Router 4，登录鉴权路由守卫

## 3. 后端架构

- **框架**: FastAPI (异步)
- **ORM**: SQLAlchemy 2.0 (asyncio)
- **验证**: Pydantic v2
- **认证**: JWT (python-jose) + bcrypt
- **迁移**: Alembic
- **数据库**: MySQL 8 + aiomysql

## 4. 项目模块

| 模块 | 说明 |
|------|------|
| 用户认证 | JWT 登录、角色鉴权 |
| 用户管理 | CRUD (仅管理员) |
| 项目管理 | 产品线管理 |
| 风险模块 | 改动风险模块维护 |
| 测试项 | 测试项字典维护 |
| 映射规则 | 模块→测试项映射 |
| 自检单 | 核心业务：创建/编辑/提交/审核 |
| 操作日志 | 全链路日志 |

## 6. 自检单编号规则

- 格式: `PRRC-YYYYMMDD-XXXX`
- 同一天内从 0001 起，递增
- 存储在 MySQL sequence 表中保证并发唯一
