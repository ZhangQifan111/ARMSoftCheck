# 使用说明

## 角色与权限

| 角色 | 说明 |
|------|------|
| 管理员 (ADMIN) | 维护用户、项目、规则，审核所有单据 |
| 开发 (DEVELOPER) | 创建自检单，填写测试结果，提交审核 |
| 评审 (REVIEWER) | 查看已提交单据，执行审核通过/退回 |
| 测试 (TESTER) | 只读查看已提交/通过的单据 |

## 开发流程

### 1. 新建自检单

入口：左侧菜单「自检单」→「新建自检单」

1. 填写基础信息（项目、版本号、变更类型、变更概述等）
2. 勾选本次改动的模块（可多选）
3. 点击「生成测试项」— 系统根据映射规则自动生成测试项
4. 逐项填写：
   - 执行情况（已执行/未执行/不适用）
   - 测试结果（通过/失败/不适用）
   - 备注（未执行、失败时必填）
5. 保存草稿或提交

### 2. 提交前检查

系统会强制校验：
- ✅ 必做项未填写 → 阻止提交
- ✅ 必做项填写「未执行」或「不适用」但无备注 → 阻止提交
- ✅ 必做项填写「通过/失败」但未选结果 → 阻止提交
- ✅ 必做项填写「失败」但无说明 → 阻止提交

### 3. 提交后

- 自动生成唯一编号：`PRRC-YYYYMMDD-XXXX`
- 状态变为「已提交」
- 进入评审人待审核列表

### 4. 审核

评审人看到所有已提交的单据，查看详情后：
- **通过**：填写审核意见，确认通过
- **退回**：填写退回原因，退回给开发修改

退回后开发重新编辑，再次提交。

## 管理员操作

### 用户管理
- 新建/编辑/禁用用户
- 设置用户角色

### 项目管理
- 新建项目（产品线）
- 设置关联的产品型号

### 风险模块管理
- 新建/编辑风险模块
- 设置风险等级（HIGH/MEDIUM/LOW）
- HIGH 模块被选中时自检单风险等级自动为 HIGH

### 测试项管理
- 维护测试项字典
- 设置默认级别（必做/建议）

### 模块-测试映射
- 维护「哪个模块需要做哪些测试」
- 设置该映射是否为必做

## 规则说明

### 风险等级计算
- 任一 HIGH 模块 → HIGH
- 否则任一 MEDIUM 模块 → MEDIUM
- 否则 → LOW

### 测试项生成
- 根据选中模块查询所有映射
- 合并去重（同一测试项来自多个模块只出现一次）
- 任一映射标记为必做 → 最终为必做
